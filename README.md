# canvas-paint-javascript

A fast, lightweight drawing app that runs in the browser. Built with HTML, CSS and vanilla JavaScript, with no frameworks or dependencies.

## Features

- Brush and eraser with adjustable size (1–30)
- Shapes: rectangle, circle, triangle and line, with optional fill
- Color presets plus a custom color picker
- Undo and redo (buttons, Ctrl+Z, Ctrl+Y), up to 30 steps
- Works with mouse, touch and stylus
- Responsive layout for desktop, tablet and phone
- Save your drawing as a PNG image

## Run locally

Open `index.html` in your browser. No build step is needed.

## Structure

```
index.html   page markup and toolbar
style.css    styling and responsive layout
script.js    drawing logic, history and export
icons/       tool icons
```
